# Existence Office 🎨

A modern and creative **design portfolio website** built to showcase visual projects, creative work, and digital experiences.

## ✨ About

Existence Office is a portfolio website focused on presenting design projects in a clean, minimal, and visually engaging way.

The website is designed to create an immersive experience while keeping the projects and visual identity at the center of attention.

## 🚀 Features

* Modern and minimal UI
* Responsive design
* Creative project presentation
* Smooth interactions & animations
* Portfolio / project showcase
* Clean visual hierarchy
* Mobile-friendly layout

## 🛠️ Built With

* HTML
* CSS
* JavaScript
* Responsive Web Design
* UI / UX Design
